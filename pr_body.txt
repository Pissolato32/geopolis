🎯 **What:** Replaced the magic string `"XXX"` with `"UNKNOWN"` in `src/server/intentParser.test.ts` and `src/gameSocket.test.ts`.
💡 **Why:** Using "XXX" for an unknown or invalid ISO country code is a code smell. While "XXX" is a user-assigned ISO 3166-1 alpha-3 code, using it this way reduces test readability and risks future collisions. `"UNKNOWN"` is explicitly invalid and much clearer.
✅ **Verification:** Ran `npm run lint && npm run typecheck && npm test && npm run build`. All tests passed. The substitution explicitly replaced `"XXX"` only where it served as a dummy country identifier.
✨ **Result:** Enhanced test readability and robustness without altering any runtime behavior.
