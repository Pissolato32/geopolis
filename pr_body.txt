## What
Extracted the duplicated `makeCountry(...)` test fixture into a shared test utility in `src/test-utils/country-factory.ts`.

## Why
This is a code health refactoring to reduce duplication across multiple test files. Previously, several test files (`src/aiDirector.test.ts`, `src/gameSocket.test.ts`, `src/selectionManager.test.ts`, `src/server/intentParser.test.ts`, `src/turnEngine.test.ts`) each defined their own identical or nearly identical `makeCountry` helper.

## Verification
- Checked that the new shared factory preserves the same semantic properties and defaults as the originals.
- Replaced the local functions with imports of the new shared factory.
- Added a basic test for the factory to ensure properties and overrides are correctly assigned, and that object mutations do not leak between test calls.
- Validated via `npm run lint && npm run typecheck && npm test && npm run build`.

## Result
Tests pass as expected, and test files are now simpler and less repetitive. No changes to production code or simulation logic were made.
